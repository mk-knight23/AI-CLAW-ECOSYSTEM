Getting Started

Initialize the CLAW ecosystem in your environment with a single command.

# Install the CLAW CLI globally
npm install -g @claw/cli

# Initialize the ecosystem in your project
claw init --matrix-mode=distributed

# Verify all specialized agents are ready
claw doctor

Core Architecture

The CLAW ecosystem is built on a distributed matrix architecture where each agent specializes in a specific domain.

⚙️

OpenClaw

The central command node. Orchestrates missions, parses goals, and enforces RALPH protocols.

🛡️

ZeroClaw

Security-first Rust agent. Performs sub-10ms audits and maintains memory-safe execution loops.

🛰️

PicoClaw

Minimal footprint agent written in Go. Ideal for edge deployment and IoT infrastructure.

🐝

NanoClaw

Collective intelligence swarm. Self-modifying logic for massive parallel data processing.

🔬

Nanobot
